# BAS | منظم يومي

تطبيق يومي عربي يجمع الجدول، ومفكرتي، وصيانة المنزل، وصيانة السيارات، والوثائق.

## تشغيل موقع الويب / PWA

جذر المستودع يحتوي على `index.html` وبقية ملفات PWA. لتفعيل الرابط:
1. GitHub → Settings → Pages.
2. Source = Deploy from a branch؛ Branch = `main`؛ Folder = `/ (root)`؛ ثم Save.
3. عند النشر سيصبح رابط الموقع مثل: `https://OWNER.github.io/REPO/`.
4. افتح الرابط في Chrome على أندرويد ثم إضافة إلى الشاشة الرئيسية / تثبيت التطبيق.

> نشر الموقع العام يجعل ملفات البرمجة ظاهرة للآخرين. لا ترفع ملفات النسخ الاحتياطية الشخصية أو بيانات الأسرة إلى المستودع.

## Android APK

مشروع أندرويد داخل مجلد `android/`. لعمل نسخة تجريبية:
1. GitHub → Actions → Build Android APK → Run workflow.
2. بعد نجاح المهمة، نزّل `BAS-Daily-Android-Debug` من Artifacts واستخرج APK.
3. هذه حزمة تجريبية مختلفة عن تطبيق مفكرتي القديم، ولا ينبغي حذفه قبل اختبار نقل البيانات.

**مهم:** نسختا الويب وAPK لا تتزامنان تلقائيًا مع بعضهما؛ التخزين المحلي لكل منهما مختلف. استخدم النسخ الاحتياطية بصيغة JSON. تطبيق أندرويد لم يُختبر ببناء فعلي بعد.

## المتطلبات المعتمدة للإصدار التالي بعد الاختبار

- استبدال أيقونة النسخة التجريبية **بنفس أيقونة مفكرتي الأصلية** داخل تطبيق أندرويد وPWA.
- مزامنة البيانات مع **ويجت مفكرتي الأصلي** بعد التحقق من آلية مشاركة بيانات تطبيق الويجت بين التطبيقات.
- تخصيص ألوان وحجم ونوع الخط، ولون خلفية الويجت وشفافيتها.
- المحافظة على بيانات التطبيقات القديمة؛ التصدير والاستيراد أولًا، وعدم حذف النسخ الأصلية.

هذه المتطلبات لم تُنفّذ بعد، ولا ينبغي افتراض وجود مزامنة مع الويجت قبل اختبارها.

## Android Widget v1.1 — واجهة الشاشة الرئيسية

أُضيف ويجت أندرويد أصلي باسم **BAS | أعمال اليوم**، يمكن تغيير لونه وخلفيته وشفافيتها ونوع خطه وحجمه وعدد البنود التي تظهر فيه، لكل ويجت بصورة مستقلة. ويعرض تاريخ اليوم، نسبة الإنجاز، ومجموعة أعمال من الجدول. الضغط عليه يفتح التطبيق.

- من الهاتف: ثبّت **APK** ثم افتحه لاستيراد نسخة JSON من تطبيق الويب إذا كانت لديك بيانات مسجلة. بعد ذلك اضغط مطولاً على الشاشة الرئيسية > **Widgets / الأدوات** > **BAS | أعمال اليوم**.
- الويجت يستخدم بيانات يومية خاصة يرسلها APK محلياً من WebView إلى `SharedPreferences`، لا إلى أي سيرفر.
- يتم تجهيز ملخص لثمانية أيام ابتداءً من تاريخ فتح التطبيق. بعدها يحتاج التطبيق إلى الفتح مجددًا لتحديث البيانات. ويجري تحديث العرض دوريًا بطلب من نظام أندرويد (قد يتأخر حسب الجهاز).
- مزامنة الويجت تعمل **مع نسخة APK المحلية**؛ نسخة GitHub Pages منفصلة ولا تنقل بياناتها تلقائياً إلى APK.
- النسخة التجريبية تُبنى عبر GitHub Actions، ويجب التأكد من نجاح خطوة `Build Android APK` قبل تنزيلها. لا يعتبر وجود ملفات المشروع دليلاً على نجاح البناء الفعلي.
- إذا كانت لديك نسخة APK تجريبية قديمة موقعة بمفتاح مختلف، قد يتعذر تثبيت النسخة الجديدة فوقها. **احفظ نسخة احتياطية JSON أولاً** قبل أي إزالة أو إعادة تثبيت.
- أيقونة التطبيق الحالية تجريبية؛ اعتماد نفس أيقونة مفكرتي السابقة يتطلب الأصل القابل للاستخراج/إعادة الاستخدام.


## v1.3 — توقيت الأعمال وتكبير الويجت

- **داخل الجدول**: اختر اليوم واضغط «⏱ تغيير الوقت» بجانب المهمة لتحديد بداية ونهاية جديدتين لذلك التاريخ فقط. تبقى الأوقات التي ثبّتها المستخدم ثابتة عند إعادة الجدولة، وتُنقل الأعمال الأخرى للأوقات المتاحة. يمنع حفظ التوقيت الذي يتداخل مع الدوام أو الصلاة أو الراحة أو أي توقيت مثبّت آخر.
- **ويجت أندرويد**: أُصلح الخط الصغير والتمدد غير الدقيق للصورة على شاشات الجوال عالية الكثافة، باستخدام `scaledDensity` للخط و`density` لتخطيط الرسم. التخصيص يدعم حجم خط من 70٪ إلى 180٪.
- **إعدادات مباشرة**: زر ⚙ في الركن الأيسر العلوي للويجت يفتح إعدادات ذلك الويجت نفسه؛ الضغط على بقية الويجت يفتح التطبيق.
- التطبيق القديم ونسخة الويب لهما تخزين منفصل. لحفظ مهامك قبل استبدال APK تجريبي احفظ نسخة JSON شاملة، فقد تختلف مفاتيح توقيع APK التجريبي بين عمليات البناء ولا يمكن تثبيته فوق النسخة السابقة.


## الإصدار V1.4: ويجت قابل للتمرير لجميع أعمال اليوم

- لم يعد الويجت يكتفي بأول مجموعة أو بعدد صفوف ثابت؛ يعرض **كل المواعيد والمهام المجدولة** ضمن قائمة أندرويد قابلة للتمرير داخل الويجت نفسه، بالإضافة إلى الأعمال غير المجدولة وبقية عناصر المفكرة المستحقة.
- رأس الويجت يعرض تاريخ اليوم ونسبة الإنجاز، وزر ⚙ يفتح الإعدادات. يمكن الضغط على أي عنصر في القائمة لفتح التطبيق.
- المساحة المرئية تعتمد على حجم الويجت، لكن بقية الأعمال لا تُحذف ولا تُخفى من القائمة: **مرّر رأسيًا** لعرضها.
- من إعدادات الويجت يمكن تغيير حجم الخط والألوان والشفافية، وإظهار الصلوات أو إخفاؤها. لم يعد عدد الصفوف خيارًا يحدّ الأعمال المعروضة.
- بعد تحديث APK افتح التطبيق مرة واحدة لتحديث بيانات الويجت. إذا لم يظهر التمرير، احذف الويجت من الشاشة الرئيسية فقط ثم أضفه من جديد.
- احفظ ملف النسخة الاحتياطية الشاملة بصيغة JSON قبل تجربة APK جديد، فقد تختلف تواقيع إصدارات Debug بين البنايات.
