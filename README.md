# BAS | منظمي الموحد — V2

## التصميم
تطبيق مستقل من الصفر، بلا مفكرة مزدوجة أو صيانة مكررة:
- الرئيسية: جدول واحد يشمل الصلوات والدوام (فترات محجوزة)، الأنشطة المتكررة المرنة، ومهام اليوم والمستحقة.
- أعمالي: المفكرة، الأفكار، المتابعات، صيانة المنزل، المناوبات، الأرشيف والإنجاز.
- إضافة: قبل أن أنسى؛ تدوين مهمة **دون تاريخ أو وقت إلزامي**.
- الملفات: سيارة واحدة = ملف كامل يشمل الاستمارة والفحص والتأمين والتجديدات والصيانة والعداد، إضافة إلى الشرائح والاشتراكات والوثائق.
- الضبط: أوقات الصلاة والدوام والأنشطة اليومية والأسبوعية، قابلة للتعديل والتعطيل.
- الويجت: عرض جميع الأعمال في قائمة تمريرية، زر إعدادات ⚙ وزر ＋ يفتح صفحة إضافة مهمة فورًا.

## ترحيل النسخ القديمة دون فقدان البيانات
يقبل التطبيق الملف الشامل `BAS_Daily_Organizer_1` أو النسخة الجديدة `BAS_Unified_V2`. يحتفظ بكامل بيانات الملف الأصلي داخل أرشيف خاص بالتطبيق. لا يعيد تشغيل الجداول القديمة المثبتة يدويًا. ترتبط صيانة البيت بالمفكرة، وصيانة السيارة بملف السيارة داخل الوثائق.

**لا تتضمن ملفات المستودع أو APK أي بيانات شخصية.** لا ترفع نسخ JSON الشخصية إلى GitHub العام. استورد النسخة الشاملة محليًا من ضبط ← استيراد نسخة سابقة.

## روابط
الويب: https://drburghash-sys.github.io/BAS-Daily-Organizer/

APK: GitHub Actions → Build Android APK → تنزيل `BAS-Daily-Android-Debug` ثم `app-debug.apk`.

تُثبت نسخة V2 تحت معرّف أندرويد جديد `sa.bas.unified` بجانب النسخة القديمة `sa.bas.daily` دون حذف بياناتها. APK تجريبي غير موقع بمفتاح إنتاجي ثابت.

## تخزين البيانات
تخزين محلي؛ لا مزامنة تلقائية بين الويب وAPK. ويجت أندرويد يستخدم بيانات APK المحلية. تتطلب الصلاة اتصالًا بخدمة مواقيت خارجية عند التحديث فقط. مشاركة واتساب تتم فقط بأمر المستخدم.


## V2.1 — صيانة السيارات داخل ملفاتها

في **الملفات ← السيارات ← صيانة السيارة والتحضير للفحص** تجد قائمة مفصلة لزيت المحرك والفلاتر والزيوت والسوائل والفرامل والإطارات والمساحات والكهرباء والفحص الدوري، بالإضافة إلى إمكانية إضافة بند خاص بكل سيارة.

- كل بند يحتوي دورية اختيارية بالكيلومترات والأشهر، وآخر تنفيذ وموعد قادم أو عداد قادم، وحالة **مطلوب / قادم قريبًا / قادم / تم التنفيذ / غير محدد**.
- الفترات الافتراضية مستعارة من برنامج صيانة السيارة السابق وهي **إرشادية وليست تعليمات صيانة معتمدة لكل طراز**. اتبع دليل مالك السيارة وراجع القيم.
- لا تظهر البنود غير المضبوطة باعتبارها «متأخرة». استخدم **⚙ المواعيد** لضبط آخر صيانة أو موعد قادم، أو **مطلوب الآن** إذا احتاج بند إلى تنفيذ فوري.
- تظهر الأعمال المطلوبة والقريبة في **الرئيسية** والويجت. الضغط على **✓ تم التنفيذ** يفتح تسجيل العداد والتاريخ والتكلفة، ثم يُحدَّث سجل السيارة وحالة الاستحقاق تلقائيًا **بدون إنشاء مهمة مكررة في المفكرة**.
- يمنع تكرار نفس البند بتاريخ وعداد متطابقين. حذف آخر سجل يعيد حالة البند السابقة إن كانت محفوظة.
- يمكن إضافة صيانة حرة داخل الملف نفسه؛ يضاف لها بند قابل للتتبع مستقبلًا.
- كل سيارات وبيانات V2 والنسخ الشاملة بصيغة `BAS_Unified_V2` متوافقة؛ لا ترفع نسخة JSON الشخصية إلى GitHub العام.
- قبل تحديث APK احفظ **ضبط ← نسخة شاملة جديدة**. قد يرفض Android تثبيت APK Debug فوق النسخة السابقة إذا اختلف التوقيع؛ لا تحذف التطبيق إلا بعد حفظ النسخة الاحتياطية والتحقق من وجودها.
